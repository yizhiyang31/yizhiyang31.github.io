# 关于本站

本站用于记录前端与后端技术学习过程，内容以「可复用、可检索、可持续更新」为目标。

## 内容范围

- 前端：JavaScript、CSS、Vue、构建工具与工程化实践
- 后端：Node.js、接口设计、数据库、部署与性能调优
- 其他：开发效率、问题排查与学习复盘

## 站点功能

- 文章列表与详情页
- 前端 / 后端分类与标签索引
- 按时间浏览的归档页
- 本地全文搜索（快捷键 `Ctrl/Cmd + K`）
- 浅色 / 深色模式与响应式布局
- Markdown 渲染与 Shiki 代码语法高亮

## 写作约定

新文章建议放入 `docs/posts/frontend/` 或 `docs/posts/backend/`，并在 Frontmatter 中声明 `title`、`date`、`category`、`tag`。使用 `<!-- more -->` 可以控制文章列表中的摘要内容。
