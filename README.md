# Yizhiyang's Tech Blog

A Chinese-language tech blog built with VuePress 2 and `vuepress-theme-hope`, focused on recording frontend and backend learning notes and engineering practices. The site is deployed on GitHub Pages.

- Site: <https://yizhiyang31.github.io/>
- Repository: <https://github.com/yizhiyang31/yizhiyang31.github.io>

## Requirements

- Node.js: `>= 22.18.0`
- pnpm: `10.x`
- Package manager: pnpm is recommended; CI uses npm

If you use nvm-windows locally, run the following first:

```powershell
nvm install 22.22.2
nvm use 22.22.2
node -v
```

If the `pnpm` command is not available, enable it through the Corepack bundled with Node:

```powershell
corepack prepare pnpm@10.32.1 --activate
corepack enable pnpm
pnpm -v
```

## Install Dependencies

Run the following in the project root:

```powershell
pnpm install
```

If dependencies were installed earlier with an older Node version and you hit errors related to the rolldown native binding, switch to Node 22 and reinstall:

```powershell
pnpm install --force
```

## Local Development

Start the dev server:

```powershell
pnpm dev
```

By default the site is served at `http://localhost:8080/`. If port 8080 is taken, VuePress automatically tries the next port — check the terminal output for the actual URL.

Build the static site:

```powershell
pnpm build
```

Build output directory:

```text
docs/.vuepress/dist
```

Preview the build result locally:

```powershell
pnpm preview
```

You can also use npm:

```powershell
npm install
npm run dev
npm run build
```

## Where to Configure Things

### Site Info and Theme Config

`docs/.vuepress/config.ts`:

- Site title, description and language
- Navbar and `activeMatch` highlighting rules
- Sidebar structure and post grouping
- Plugin config for Blog, Sitemap, SEO, SlimSearch, etc.
- Chinese title mapping for auto-generated index pages
- Browser `theme-color` matching the brand color

### Client Layout Logic

`docs/.vuepress/client.ts`:

- The `/tag/` index page shows the content of the tag with the most posts by default
- `/category/backend/` and `/category/engineering/` redirect to the first post in the sidebar by default
- Category pages reuse the custom Blog layout

### Global Styles

`docs/.vuepress/styles/index.scss`:

- Brand color: `--vp-c-brand-1`, currently `#2a69ed`
- Pill-style navbar styling
- Card-style sidebar styling and spacing
- Detail styles for breadcrumbs, timeline, code blocks, etc.
- Hide "Prev / Next" links at the bottom of posts

## Adding a Post

Posts live under `docs/posts/`. The recommended frontmatter is:

```md
---
title: Post Title
author: yizhiyang
date: 2026-11-21
category:
  - 后端
tag:
  - Go
  - 学习笔记
---
```

Conventions:

- `category` determines which `/category/.../` page the post belongs to
- The directory structure affects breadcrumbs, so keep directory names consistent with categories
- Put engineering posts in `docs/posts/engineering/`
- Put Go series posts in `docs/posts/backend/golang/`
- If you move or rename a post path, use `redirectFrom` in the frontmatter to keep the old link working

## Deployment

After pushing to the `main` branch, `.github/workflows/deploy.yml` automatically:

1. Uses Node.js `22.18.0`
2. Runs `npm install`
3. Runs `npm run build`
4. Makes sure `docs/.vuepress/dist/.nojekyll` exists
5. Uploads and deploys `docs/.vuepress/dist`

The Node version in the deploy workflow is kept in sync with `engines.node` in the project's `package.json`.

## FAQ

### Node Version Too Low

If you see `Unsupported engine` or a rolldown native binding error, check the current Node version:

```powershell
node -v
```

It should print `v22.x`. After switching, remove the old dependencies and reinstall:

```powershell
pnpm install --force
```

### pnpm Command Not Found

Run:

```powershell
corepack enable pnpm
```

Then reopen the terminal.

### Changing the Brand Color

The brand color is maintained in a single place: `docs/.vuepress/styles/index.scss`. Remember to also update `theme-color` in `docs/.vuepress/config.ts`.
